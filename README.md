# Portfolio Website — Editorial Layout

Personal portfolio website designed and developed using **HTML and CSS (Vanilla)**.  
The project explores an **editorial-inspired layout**, focusing on typography, grid systems and visual hierarchy.

🔗 Live site: https://arknt.github.io/repository-2025-2026

---

## Project Overview

This website serves as a personal portfolio showcasing selected projects through a clean, minimal and editorial visual language.

The main goal of the project was to:
- Experiment with **advanced CSS layouts**
- Build a fully **responsive website**
- Create a strong **typographic hierarchy**
- Avoid templates and frameworks in favor of a custom solution

---

## Technologies Used

- HTML5 (semantic structure)
- CSS3
  - CSS Grid
  - Flexbox
  - `clamp()` for responsive typography
  - Media queries
- Git & GitHub
- GitHub Pages for deployment

No external CSS frameworks or JavaScript libraries were used.

---

## Features

- Fully responsive layout (mobile, tablet, desktop)
- Editorial-style grid compositions
- Fullscreen sections (`100vh`)
- Dynamic typography using `clamp()`
- Project index navigation
- Custom case study introduction layouts
- Hover interactions and transitions

---

## Accessibility

- High color contrast between text and background
- Semantic HTML structure
- Responsive font sizing
- Motion-reduction support via `prefers-reduced-motion`

---

## AI Usage

Artificial Intelligence tools (ChatGPT) were used during development to:
- Assist with CSS layout structuring
- Debug layout and positioning issues
- Refine responsive behavior
- Improve code clarity and organization

All AI-assisted steps are documented in the `/docs` folder.
